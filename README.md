# 概要
- 目的: [giasupeのポートフォリオ](https://giasupe.github.io/)の構築を通じて、HTMLなどの理解を深めるためのプロジェクト
# 開発環境
- OS: `Windows 11 Home`
- 開発ツール: `VSCode`
- バージョン管理: `Git`,`Github`
# リポジトリ
- URL: https://github.com/giasupe/giasupe.github.io
- ルール: プルリクエスト必須
# 確認用コマンド
- 準備: `npm install`
- HTMLの検証: `npm run lint:html`
- ローカルプレビュー: `npm run serve` (http://localhost:8000)
