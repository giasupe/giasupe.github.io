# giasupe portfolio

giasupeのポートフォリオサイトです。Web制作を学びながら、制作物と現在の技術を紹介しています。

## 使用技術

- React
- TypeScript
- Vite
- CSS
- Git / GitHub
- GitHub Pages

## 開発環境

- OS: `Windows 11 Home`
- 開発ツール: `VS Code`

## ローカルでの確認

```shell
npm install
npm run dev
```

本番用ファイルを確認する場合は、次のコマンドを実行します。

```shell
npm run build
npm run preview
```

## 主な構成

- `index.html`: Viteのエントリーポイント
- `src/App.tsx`: 1ページLPの構成とUI
- `src/main.tsx`: Reactの起動処理
- `src/styles.css`: モバイルファーストのスタイル
- `images/`: 作品画像
- `public/`: faviconなどの静的ファイル
- `legacy/`: 移行前の未使用ファイル
